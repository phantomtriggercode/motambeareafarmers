# Motambarea Farmers — public website

Static information site built with semantic HTML, responsive CSS and vanilla JavaScript. No framework, package manager, backend or build step is required.

Open `index.html` in a browser or serve the folder with a static web host.

## Pages
Home, About, Cocoa Buying, Coffee Buying, Our Farmers, Market Prices, Quality & Traceability, News & Updates, Contact.

## Before launch
- Replace contact placeholders in `contact.html` with verified company channels. Configure the form action to the verified business email.
- Edit `priceBoard` in `js/prices.js` only with verified prices, source and update time. Values are demo placeholders, not a live offer.
- Verify buying points, hours, quality requirements and operating information.
- Replace generated CSS artwork with licensed company photography when available.
- Confirm domain canonical URLs.

No company history, certifications, statistics, clients or partnerships are fabricated.

```
index.html, about.html, cocoa.html, coffee.html, farmers.html,
prices.html, quality.html, news.html, contact.html
```
